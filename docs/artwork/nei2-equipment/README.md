# NEI 2 equipment artwork

Created with the built-in image-generation tool from the corresponding 32x32 upstream icon references. Full-size transparent PNG masters are retained here; game assets are resized to 128x128 RGBA PNGs under `soh/assets/custom/textures/icon_item_custom/`.

## Prompt set

Shared direction: Repaint the low-resolution reference as a crisp, clean stylized 3D-rendered Zelda inventory icon. Preserve the item's design, silhouette, orientation and colors, not the pixelation. Genuine transparent background with alpha; no checkerboard, ground, cast shadow, text or extra items. Center the entire item inside a square canvas with 10 percent clear margin and no clipping. Smooth clean outlines, readable at 128x128, simple shapes and restrained shading matching classic game inventory artwork.

- MagicTunic: One headless short-sleeved tunic, front view, brown neck opening, white front lacing and golden belt. Mustard golden-yellow fabric.
- SagesTunic: One headless short-sleeved tunic, front view, brown neck opening, white front lacing and golden belt. White fabric with subtle light-gray shading.
- ClimbBoots: A pair of olive-green climbing boots with silver metal toe caps, three-quarter view, toes pointing lower left.
- RocBoots: A pair of golden tan ornate Roc boots with winglike flares, three-quarter view, toes pointing lower left.

These are newly interpreted artwork, not recovered original high-resolution upstream sources. Device visual verification remains required.
